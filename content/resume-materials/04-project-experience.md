## 博士阶段学术研究项目 Doctoral Research Projects

### 项目 1: 浙东引水工程受水区降雨特征研究

| 字段 Field                                    | 内容 Content                                                                           |
| --------------------------------------------- | -------------------------------------------------------------------------------------- |
| **课程/研究课题 Course/Research Topic** | 博士研究课题 / Doctoral Research Project                                               |
| **项目名称 Project Name**               | 浙东引水工程受水区降雨趋势与多尺度变异性研究                                           |
| **项目类型 Project Type**               | 个人研究项目 / Individual Research Project                                             |
| **角色 Role**                           | 第一作者 / First Author                                                                |
| **项目时间 Period**                     | `<!-- 🔴 TODO: 请补充项目起止时间 -->` 和浙东引水一样 From 【待补充】 To 【待补充】 |

**项目内容 Project Briefing**:

为揭示浙东引水工程受水区的降雨变化规律以优化工程调度，本研究分析了工程影响下15个典型子区域1961年至2022年的长序列日降雨数据。采用Mann-Kendall趋势检验、Sen's斜率估计和多尺度滑动窗口分析等方法，系统考察了降雨的时空分布、长期趋势、多尺度变异性及区域相关性。

**主要工作**:

- 收集并处理1961-2022年长序列降雨数据
- 应用Mann-Kendall趋势检验和Sen's斜率估计进行趋势分析
- 进行多尺度滑动窗口分析，揭示不同时间尺度的降雨变异性
- 计算Hurst指数评估趋势持续性
- 分析区域间降雨相关性

**项目成果 Achievements**:

- 发现所有子区域年降雨量均呈显著上升趋势（p<0.05）
- 揭示了增幅空间分异规律（沿海>河流域>丘陵）
- 研究成果发表于《水电能源科学》（2025年）
- 为浙东引水工程适应性调度提供了科学依据

### 项目 2: 浙江省用水量驱动因子分析与预测模型研究

| 字段 Field                                    | 内容 Content                                                                            |
| --------------------------------------------- | --------------------------------------------------------------------------------------- |
| **课程/研究课题 Course/Research Topic** | 博士研究课题 / Doctoral Research Project                                                |
| **项目名称 Project Name**               | 基于主要驱动因子筛选法和深度学习算法的浙江省动态需水量预测                              |
| **项目类型 Project Type**               | 团队研究项目 / Team Research Project                                                    |
| **角色 Role**                           | 第二作者，核心参与者 / Second Author, Core Contributor                                  |
| **项目时间 Period**                     | `<!-- 🔴 TODO: 请补充项目起止时间 --> 绍兴 承载力模型 ` From 【待补充】 To 【待补充】 |

**项目内容 Project Briefing**:

收集了浙江省2000—2020年各用水行业需水量数据，采用基于Spearman秩相关分析的主要驱动因子筛选法筛选了影响各行业需水量的主要驱动因子，进而构造了改进的长短时记忆(LSTM)神经网络需水量预测模型。

**主要工作**:

- 负责LSTM神经网络模型的构建与优化
- 进行模型参数调优和性能评估
- 与传统单变量LSTM、CNN、SVR模型进行对比分析
- 实现动态滚动预测功能

**项目成果 Achievements**:

- 改进的LSTM模型预测精度显著高于其他3种模型
- 研究成果发表于《水科学进展》（2024年）
- 预测方法在实际水资源规划中得到应用

### 项目 3: 河网非均匀沙输移研究

| 字段 Field                                    | 内容 Content                                                                                |
| --------------------------------------------- | ------------------------------------------------------------------------------------------- |
| **课程/研究课题 Course/Research Topic** | 博士研究课题 / Doctoral Research Project                                                    |
| **项目名称 Project Name**               | 考虑侧向出沙的河网非均匀沙输移                                                              |
| **项目类型 Project Type**               | 团队研究项目 / Team Research Project                                                        |
| **角色 Role**                           | 第三作者 / Third Author                                                                     |
| **项目时间 Period**                     | `<!-- 🔴 TODO: 请补充项目起止时间 -->` 约2014-2016 这个时间对的 / Approximately 2014-2016 |

**项目内容 Project Briefing**:

针对引水进入河网造成的泥沙淤积问题，研究水流在主干河道行进时挟带泥沙向连通支流扩散的侧向出沙现象。根据杭州西部河网实测资料，建立了适用河网的对数型非均匀沙挟沙能力公式，并导出了考虑时变侧向出沙的河网非均匀沙输移计算方法。

**主要工作**:

- 参与河网泥沙实测数据收集与处理
- 参与挟沙能力公式的建立与验证
- 参与侧向出沙计算模型的开发
- 进行模型验证与误差分析

**项目成果 Achievements**:

- 建立了考虑侧向出沙的河网输沙微分方程
- 研究发现侧向出沙约占淤积总量的11%
- 研究成果发表于《水利学报》（2016年）
