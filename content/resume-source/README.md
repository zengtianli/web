# 模块化简历系统

## 目录结构

```
resume/
├── _基础信息/          # 个人信息、教育经历
├── _技能模块/          # 按领域分类的技能
├── _项目模块/          # 按业务领域分类的项目
├── _学术成果/          # 论文、专利、软著
├── _荣誉奖项/          # 荣誉和奖项
├── _科研经历/          # 学术研究经历
└── _生成简历/          # 最终输出的简历版本
```

## 使用方法

### 新增项目

1. 在 `_项目模块/` 下选择合适的业务分类目录
2. 创建 `项目名.md`，按模板填写
3. 标注 `highlight: true` 表示重点项目

### 新增论文/专利/软著

1. 在 `_学术成果/` 对应子目录创建 `.md`
2. 按年份命名：`2025-论文简称.md`

### 生成简历

1. 根据目标岗位，选择合适的项目模块
2. 选择技术向或方案向描述
3. 拼接到 `_生成简历/` 下的模板

## 项目模块模板

```markdown
---
title: 项目名称
period: 2024.10-至今
role: 技术负责人
keywords: [关键词1, 关键词2]
workload: 1012小时
highlight: true
---

# 项目名称

## 项目主旨
一句话描述

## 主要职责
- 职责1
- 职责2

## 项目成果
- 成果1（量化）
- 成果2

## 技术栈
Python, QGIS, ...

## 技术向描述
（强调技术实现）

## 方案向描述
（强调业务理解和方案设计）
```
