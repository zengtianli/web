# 梯级水库群多目标联合调度模型

## 项目主旨

针对梯级水库群发电优化调度需求，开发基于水量平衡迭代算法的多目标联合调度模型，支持多水库多时期联合调度，实现发电效益最大化与水资源高效利用。

## 主要职责

### 模型开发
- 设计并实现水量平衡迭代求解算法，处理多水库间的水力联系
- 开发梯级水库发电优化调度核心模块
- 支持日/旬/月多时间尺度调度计算

### 软件开发
- 基于 Python + PyQt 开发 GUI 交互界面
- 实现六大功能模块的集成
- 开发调度结果可视化分析功能

## 项目成果

- 软件著作权 1 项（申请中）
- 模型成功应用于实际梯级水库调度

## 技术栈

Python, PyQt, NumPy, Pandas, 水量平衡算法, 多目标优化
