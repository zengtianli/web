# GIS 空间分析技能

## 核心能力

| 技能 | 等级 | 应用项目 |
|------|------|----------|
| 空间分析方法 | 精通 | 岸线规划、洪水风险图 |
| 矢量数据处理 | 精通 | 河道切割、堤防赋值 |
| 栅格数据处理 | 熟练 | DEM分析、流域划分 |
| 遥感影像处理 | 基础 | 土地利用分析 |

## GIS 软件

| 软件 | 等级 | 说明 |
|------|------|------|
| ArcGIS | 精通 | 主力 GIS 平台 |
| QGIS | 熟练 | 开源替代、Python 集成 |
| Python GIS 库 | 熟练 | geopandas, shapely, rasterio |

## 典型应用

| 场景 | 方法 |
|------|------|
| 河道中心点生成 | 几何计算 |
| 堤段切割 | 空间分割 |
| 堤防高程赋值 | 空间连接 |
| 岸线分级分类 | 叠加分析 |

## 技能描述变体

### 技术版
精通 ArcGIS、QGIS，熟练使用 Python GIS 库进行空间数据处理与分析。

### 方案版
具备 GIS 空间分析能力，能够将地理信息技术应用于水利规划与风险评估。
